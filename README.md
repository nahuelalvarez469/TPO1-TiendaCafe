# La Hoja — Casa de Té

Trabajo Práctico Obligatorio 1 de Frontend. Proyecto académico grupal: clonación de la **estructura y estilo general** de Tienda de Café con una temática de tienda de té.

## Páginas

- `index.html` — Inicio
- `tienda.html` — Nuestro té y catálogo
- `tutoriales.html` — Guía para preparar té
- `menu-tienda.html` — Carta de muestra
- `trabaja-en-tdc.html` — Trabajá con nosotros
- `franquicias.html` — Información para franquicias
- `contacto.html` — Contacto

## Tecnologías

HTML5 semántico, CSS3 (Flexbox, Grid, box model, pseudoclases y combinadores), JavaScript mínimo para el menú mobile y demostración de formularios. Fuentes DM Sans y Playfair Display (Google Fonts, con tipografías alternativas si no hay conexión).

## Cómo ejecutar

Abrir `index.html` con el navegador. También puede utilizarse **Live Server** en VS Code. Las rutas son relativas y todas las ilustraciones SVG están guardadas en `img/`, por lo que el sitio funciona localmente sin conexión; solo las fuentes externas requieren conexión.

## Responsive

Se incluyen los cuatro cortes solicitados en la consigna: 1080px, 768px, 480px y 375px.

## Git y GitHub (trabajo grupal)

Se recomienda crear un repositorio, hacer una rama por página o tarea, trabajar mediante commits descriptivos y unir los cambios con pull requests. Publicación posible con GitHub Pages, seleccionando la rama principal y la carpeta raíz.

## Aclaraciones

La marca **La Hoja**, los productos, los precios, los formularios y las franquicias son ficticios. Los formularios solo muestran una confirmación en pantalla: **no se envían ni almacenan datos**. No se implementan carrito ni compras porque no son parte de los requisitos del TPO. Se incluyen ilustraciones originales de muestra en SVG.
